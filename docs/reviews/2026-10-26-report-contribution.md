# 结算贡献占比验收

## 结果与范围

逐只与同种结算战报增加当前排序指标的全队合计、行内占比及静态细条，沿用五种指标和四列表格。两种模式以实际参战名单关联逐兽记录求分母，包含重伤，不计备战或无关战报行。任何成员缺失该项或数值无效时整表不计算占比；合计为0明确说明原因，无比例条。完整正分母下，真实0为0.0%，微小正值为<0.1%，其余保留一位小数，条宽使用未舍入比例。

纯投影与共享展示组件没有新增state、effect、计时器、缓存或持久化。按React与simplify自审，计算只读、不写回战报；没有修改模拟规则/数值、RNG、schema2/contentv24、3格接敌、存档、导出、收藏、依赖、素材或原npm命令。占比只反映当前指标，不等于DPS、强度或胜率；产钱仍只统计桃产出，不等于最终入账。
