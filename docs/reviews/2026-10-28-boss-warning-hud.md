# 持续横扫预警验收

上一轮已本地提交 `0b25cc2 完善首领阶段血条与战场标记`。本轮新增开发留工作区，没有推送。

## 实现

在首领生命条下增加真实预警摘要。bossWarnings从存活首领和本场warnings只读派生，按due、source、row、echo排序，不重排源数组；行号转为从1起。同一行的首段与追击分别保留，最多显示最早两条，超出时说明额外数量。

正剩余时间向上取整至0.1秒，到期显示“待判定”；冻结状态优先显示“冻结中 · 释放延后”。没有本地倒计时、effect、状态或新动画，暂停和待选天赋自然保持。释放或来源倒下/退场后消失。不预测下次技能，也不保证伤害命中，说明实际释放时重新判定。

沿用深绿主题，横扫暖色、追击淡紫并有文字区分，允许窄屏换行。使用带名称的group和列表，不用aria-live逐帧播报。保留既有短播报、行高亮及暂停详情。

不改战斗引擎、数值/随机、3格接敌、content v24/schema2、存档/收藏格式和容量、素材、依赖或npm命令。
