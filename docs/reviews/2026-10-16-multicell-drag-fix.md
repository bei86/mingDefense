# 多格灵兽相邻拖动修复 / 2026-10-16

用户反馈横两格岩甲豚向右拖不动。复现：从左格向右拖一格，释放处仍属于原灵兽，UI将其当成点选自身并取消选择，位置没有变化。另外，从非左上角占格抓取时没有记录偏移，会把指针所在格误当成新的左上角。

修复保留抓取格相对左上角的偏移，拖动时允许新旧占格重叠。拖动预览与提交共用落点解析；命中其他灵兽时仍按指针所在格尝试合成，非法占格继续由原事务校验回退。普通点击自身仍取消选择，多格占地保持不透明。

验证结果：

- 新增5项回归：横两格从左右两格向右平移、2×2从右下格向上平移、带抓取偏移的同类合成、非法落点不改变状态。
- `npm.cmd test`：7个文件、70项通过；`npm.cmd run build`通过；定向Prettier和`git diff --check`通过。
- 本机开发场景 `http://127.0.0.1:5173/?playtest=boss`（不写存档）实测：岩甲豚3–4列→4–5列→5–6列，并向左返回；青锋隼从右下格抓取后从2–3行移到1–2行；岩甲豚落在鼠上时拒绝合成且原阵容保持。
- 390×844浏览器视口中再次右移一格成功。控制台无warn/error。验证后恢复默认视口；这不是手机真机触控验证。
