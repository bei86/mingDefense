# 烬灵鼠开发版动作预览验收记录

用户要求“提交并下一步”。先将上一轮三组动作、素材和提示词以6c3d3c5「接入烬灵鼠待机受击与重伤动画」本地提交，确认工作区干净，再实现本次独立动作预览。新改动未提交、未推送。

## 行为

开发版直接打开 http://127.0.0.1:5173/?preview=mouse-motion ，或在开发试玩菜单点击「角色动作预览」。启动在GameApp导入前分流，不创建Session、不访问战役与偏好存储。正确preview优先于其他试玩参数，未知值沿原启动流程；入口按当前pathname重新构造，保留嵌套部署位置。

页面使用当前发布的四组WebP和同一个ArtLayer图片池。上方显示52逻辑像素单格比例及半透明攻击首帧参考，下方放大4倍，显示格线与共同脚底基准。使用与战场相同的42×36可用空间和168×216参考尺寸，重伤原点也复用已接入定义，不因每帧内容变化而调整大小。

支持四动作切换、播放/暂停、重播、上一帧/下一帧、帧滑条、1倍/2倍、减少动态、深浅背景。待机200ms每帧循环，攻击70ms、受击60ms、重伤80ms每帧，一次动作完成后停末帧。末帧点击播放从头重来，手动跳帧暂停并同步计时游标。攻击顺播是素材检查节奏，不模拟真实前摇、释放或投射物。

系统减少动态优先，启用后暂停并固定所选动作首帧、重伤末帧，禁用自动播放与逐帧；关闭后保持暂停，可主动播放。切后台、失焦冻结，恢复首帧丢弃旧delta，超长delta最多取100ms。播放状态不持久化，返回正式页面才按正常检查点加载；另提供八灵实战链接。

加载超时沿用8秒、不重试；缺某组纹理时列出缺失动作、暂停该组预览、保留其他可用动作，并提供重新加载。画布初始化同步失败时显示错误。预览不借其他动作填补缺失，避免误判素材通过。组件清理时销毁Phaser、移除focus/blur/visibility监听；系统偏好监听也在卸载时移除。背景和逐帧状态不重建场景，React仅在帧或控件状态改变时更新。

## 浏览器待验收

用户反馈页面只显示背景后，查明全屏固定body::before装饰层会覆盖未定位的预览容器。已在motion-preview.css为页面补上position:relative和z-index:1，沿用启动页的层级处理。修复后相关4文件9项测试、typecheck和格式检查通过；这些检查不构成浏览器目视通过。

尝试CUA连接预览页面，返回“The browser access host is unavailable”。本轮没有浏览器截图、DOM交互、实际Phaser绘制、窄屏/Retina、系统减少动态切换或缺图模拟验收。未改用其他桌面自动化，未访问正式战役标签或存档，无须恢复视口。

浏览器恢复后核对：四动作对应图片与帧数、暂停逐帧和重播、重伤落点与末帧、同格/4倍对照、暗浅背景透明边缘、后台恢复、系统减少动态、单张缺图提示、反复进出预览不残留画布、窄屏横向溢出，以及跳往八灵和正式战役后的正确来源。素材预览不能替代真实战斗里连续攻击、受击覆盖、重伤淡化和火球衔接的验收。
