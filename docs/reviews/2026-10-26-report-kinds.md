# 结算同种灵兽汇总验收

## 结果与范围

逐兽战报新增「战报查看方式」，默认逐只，可切到同种汇总。每种显示只数、重伤数、各阶数量和伤害/承伤/施盾/吸收/产钱合计；不同阶相加，包含重伤者，备战不计。共用上一轮五种排序，模式切换及收起重开保留当前选择，切回逐只保留编号、阶数、位置和重伤状态。

`report-kinds.ts`以战斗实例为参战名单，关联逐兽记录；该种每个成员均有有限数值才给出该项合计，部分缺失标未完整记录，全部缺失标未记录，完整0先于缺失，同值按既有八灵顺序。五项独立计算，不混算提供护盾与实际吸收。

`ReportUnits.tsx`保留局部metric和mode，复用排序选择及表头，不新增effect、计时器、存储或缓存。按照React与simplify自审：投影是纯函数，返回新组/阶数分布/指标对象；最多八组无需memo。表格保持四列，汇总表固定布局并允许长阶数分布/未知标签换行。没有修改模拟规则/数值、RNG、schema2/contentv24、3格接敌、存档、导出、收藏、依赖、素材和原npm命令。
