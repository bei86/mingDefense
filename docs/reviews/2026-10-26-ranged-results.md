## 使用与范围

运行 `npm.cmd run dev`，打开 `http://127.0.0.1:5173/?playtest=ranged8`。展开浅色试玩区，再展开「本标签页最近战果」。每个案例各保留原方案、远程减少的最近完整战果，可以复制、下载 Markdown 或手动复制只读文本。没有完成的一侧显示「未试玩」。

记录使用独立 `sessionStorage` key `ming-defense:dev:ranged8-results:v1`，最多3案例×2方案。刷新、切换方案、切换案例和重置开局保留；关闭标签页通常清空，浏览器恢复会话可能恢复。清空按钮删除全部案例的试玩记录。此数据不进入正式战役存档、阵型、战报收藏或备份。

成功开战时克隆实际开战档，支持玩家先调整阵容。只有胜败确定、天赋选择完成且胜利已结算后才捕获；准备、进行中、中断不覆盖上次战果。终局按战斗实例保存一次，面板默认折叠；顶部与结算页同时只挂载一份。

表格比较胜负、模拟用时、余血、承伤、击杀经验、聚灵实际生效时长；报告另含伤害、击退、收入、UTC捕获时间、开战阵容、完整开战档和结束累计天赋。开战档比较完整preparation，结束天赋忽略0层及键顺序。同档、同最终天赋、同聚灵时长不能证明操作时机和顺序一致，不自动得出优劣或玩家胜率。

旧版本、坏JSON、重复槽位、超过6条、过大数据或无效开战档会拒读并保留底层原文。上限512KiB，包含试玩规则版本和内容版本。存储失败时当前结果仍可在本页导出，但导航可能丢失；清空失败保留界面已有记录，完成结果可重试保存。
