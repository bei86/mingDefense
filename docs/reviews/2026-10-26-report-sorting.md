# 逐兽战报多维排序验收

## 结果与范围

结算逐兽战报增加五种降序：伤害、承伤、提供护盾、护盾吸收和产钱。默认伤害，分值相同按实例编号升序；缺失或非有限数值显示未记录，排在已记录0之后。每只显示编号，两项护盾记录始终可见，护盾排序突出相应值。保留四列表、阵型复盘图和重伤时间线。收起重开保留当次指标，离开结算后不持久化。

`report-unit-sort.ts`只读排序，复制数组不写字段；`ReportUnits.tsx`管理单个局部指标和逐兽表，`BattleReport`保留复盘结构。按React与simplify自审，无新effect、计时器、持久化或重复派生状态；不为最多36行添加额外memo。模拟规则/数值、RNG、schema2/contentv24、3格接敌、依赖、素材、原npm命令均保持。
