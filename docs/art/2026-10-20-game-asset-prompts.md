# 《灵林守阵》游戏素材生成提示词

适配当前30关原型：8种灵兽、8类普通敌人、6位首领。以下为建议美术方向和可复制提示词，不改玩法与数值，也未接入图片资源。

## 1. 统一画风与生成方式

推荐“国风Q版2D手绘灵兽”：森林青绿为环境色，角色用暖橙、桃粉、冰蓝、淡紫区分；哑光上色、少量高光、清楚轮廓。比细密水墨更容易在手机棋盘上辨认，也方便后续制作动作。水墨可用于远景；剪纸适合另一套整体风格，不与这套角色混用。

每次只生成一个资产。**角色生成时，把下面的通用前缀＋对应角色段落＋负面提示词一起输入。** 场景、UI和特效使用各自提示词，不加角色前缀。


说明：负面词不能保证模型完全遵守，生成后仍需检查。若工具不支持透明输出，改用无纹理浅米色纯底，后续抠图；把“透明背景”改掉，不要同时要求两种背景。保留原始高分辨率图。

### 尺寸与构图

下表画布比例是构图建议，不是必须支持的生成器参数。优先保留角色比例；工具不支持长宽比例时，先用最接近的比例出图，再补透明边，不拉伸角色。占格范围最终由游戏程序控制，素材不绘制占格底板。

| 用途/角色     | 建议原图            | 构图要求                                 |
| ------------- | ------------------- | ---------------------------------------- |
| 鼠、桃、狐    | 1024×1024           | 紧凑方形轮廓                             |
| 岩甲豚，横2格 | 2:1，长边至少1024   | 身体横向，武器不另占一大片空白           |
| 青锋隼，2×2格 | 1024×1024           | 双翼和身躯构成接近方形轮廓               |
| 穿林猿，横3格 | 3:1或可用的横图比例 | 猴身＋横持长棍形成宽轮廓，不拉宽身体     |
| 霜尾鲤，竖3格 | 1:3或可用的竖图比例 | 鱼身与尾鳍纵向延展，不拉长头部           |
| 磐拳熊，竖2格 | 1:2或可用的竖图比例 | 直立厚重轮廓                             |
| 普通敌人      | 1024×1024           | 大致相同视觉体量，不因留白不同忽大忽小   |
| 首领          | 1024×1024           | 比普通怪更有分量，武器和外翼收在主体附近 |
| 技能图标      | 512×512             | 大图形、少细节；不要把角色立绘缩成图标   |

1024是生成原图的建议，游戏使用时另做裁边、缩图和图集。角色脚底或悬浮最低点作为对齐参考，后续同角色所有动作必须保持相同锚点。光环、护盾、伤害数字与等级标记单独制作或由程序绘制。

## 9. 建议生成顺序与交付检查

1. 先生成烬灵鼠、灵金桃、青锋隼、林间战场底图，检查角色是否和场景协调；选定烬灵鼠作为画风参考。
2. 用参考图补齐另外5只灵兽。每次只生成一只，保持相同画风、光向与描边强度。
3. 补6类普通敌人，再做咒影和碎岩灵，注意区别物种和视觉体量。
4. 做6位首领普通阶段，再参考编辑6张二阶段图。
5. 补图标、必要UI底板和技能特效；最后制作动作。

至少检查：是真透明而非棋盘格截图；武器尾巴完整；无模型生成的中文、血条或水印；缩到48像素后身份清楚；同角色动作和二阶段不漂移；角色本体没有模糊大光晕；多格角色没有被横向或纵向拉伸。

按上述英文文件名交付即可。角色、场景、UI、特效分别存放，保留生成原图和抠图后的透明PNG。图片生成完成后仍需要在游戏内处理锚点、显示尺寸、加载和动画；本提示词文件没有替换当前几何占位渲染。
