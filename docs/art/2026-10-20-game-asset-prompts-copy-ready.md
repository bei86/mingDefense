# 《灵林守阵》游戏素材提示词 · 直接复制版

共58项静态素材。每项下面的代码块都是完整提示词，已经合并通用画风、角色描述和必要限制；无需再拼接，也没有需要手工替换的描述占位符。

## 使用方法

1. 找到要生成的素材，复制它下面的整个代码块，粘贴到生图工具；每次只复制一项。
2. 先生成烬灵鼠，选出满意的一张。后续角色可附上它作为画风参考；角色外形仍按各自文字生成。
3. 首领二阶段必须附上同一首领的普通阶段图；对应条目会写明附件文件名。
4. 图片生成后按条目里的文件名保存。透明素材检查是否真正透明，别把棋盘格背景保存进图片。

本文件只包含提示词；生成图片后再交给我整理和接入游戏。第一批先做静态角色，动作和高阶外观之后再补。
