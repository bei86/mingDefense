# 暂停查看后续敌袭

目标：玩家在战斗中暂停后能判断尚未出场的固定敌袭，补齐现有战场详情只展示已上场实例的缺口。

选择在战场详情增加“后续敌袭”页签。相比常驻倒计时，避免挤占守卫画面；相比重新生成完整敌情，直接读取本场已生成的队列和游标，更准确且不消耗随机数。

- 从Combat.spawns.slice(spawnIndex)读取未执行队列，沿现有顺序，不以时间过滤；同一时刻的首领/普通敌人均保留，未写kind沿战斗逻辑按wolf。
- 显示固定未出场数量、剩余各类数量，及接下来最多8只的名称、计划出场时刻、距当前战斗时钟的时间和入口列。小数秒向上保留1位，已到时未执行显示“待出场”。只展示固定队列，召唤/分裂不预估。
- 明示时间为游戏内时间；暂停和选天赋时冻结，倍速影响现实等待，不把计划出场当抵达阵线或下次攻击。固定队列清空后不暗示关卡结束；场上与衍生敌人仍需处理。
- 沿用现有灵兽/敌人两页的选择与关闭方式，不重写其逻辑；三页按钮保持44px触控高度、320宽不溢出。只有当前页计算队列，视图纯派生，不新增时钟、存储、请求或特效。
- 无战斗显示无数据；战斗结束时标明未执行队列不会继续出场，不承诺剩余敌人仍会刷新。
- 保持连续出怪、3格接敌、前排/阶数/仇恨、全部规则与数值、RNG、v24/schema2、依赖、素材、默认启动命令。本轮新功能不提交、不推送。

验收覆盖50关真实队列、游标而非时间过滤、同刻出怪、最后一只/队列清空、首领名称、默认wolf、场上衍生不计、只读与暂停不推进；浏览器检查暂停入口、三页切换、320/390滚动与关闭继续、正式生产存档恢复。
