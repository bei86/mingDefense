# 战斗动效与基础音效

用户“开始下一步”已确认上一轮提出的角色动效、首领提示、基础音效及手机表现检查。本轮由当前会话实施，完成后保留未提交，不重复申请批准。

采用现有静态立绘的轻量变换：待机呼吸、移动起伏、释放攻击时小幅前倾、真实承伤时闪光、敌人退场淡出。角色位移上限约6.3逻辑像素，血条和实际坐标不动，不增加摄像机晃动；冻结敌人不播放移动动作。重伤灵兽淡至原有低透明度占位。支持系统减少动态效果设置。

新增独立只读CombatFeedback快照，接在现有25ms游戏循环后，与Phaser帧率解耦。它维护自己的时钟、演员状态、最多24个退场影像和一条首领提示。所有数据只存在表现层，不进入Session、RNG或存档。开战/回滚/重试清空旧反馈，暂停和天赋选择冻结动效，2倍速同步推进；读档不重播旧攻击、产钱或结果音。

首领出现、进入二阶段和新横扫预警触发短提示；放在战场上方已有HUD边界，不遮挡战场角色，不阻塞战斗，不改变预警时机。横扫现有行标记保留。首领/阶段提示优先于普通预警，提示按表现时钟结束。

Web Audio在用户首次指针/键盘操作时初始化，合成本地短音，无网络和新素材依赖。覆盖按钮、部署/合成、攻击、产钱、升级、首领/阶段/横扫与胜负。默认开启，整备页及暂停菜单均可静音，独立偏好键ming-defense:audio不改战役档；存储失败仍可切换。事件只播放一次，不积压；全局最短间隔、单类间隔和12个振荡器上限控制满阵声量。不支持音频或恢复失败时安静降级，游戏照常运行。暂停/离屏停止旧声音，界面操作音可单独短播。

测试涵盖真实Session事件、首次基线/回滚/暂停/倍速/冻结、护盾到期不伪造受击、死亡及池上限、短音节流/静音/失败/释放资源。浏览器390/320检查真实操作、首领提示、暂停、设置保留和截图，音频设备实际听感及手机真机性能单独标明验证范围。保持v22所有规则、40关范围、原图和已有npm命令。
