# 暂停攻击光环来源定位

目标：在暂停详情展开攻击灵兽的「战斗当前属性」后，直接查看实际提供攻击光环的月音狐，避免玩家根据名字猜测同名实例。

采用现有来源列表逐只定位。单纯保留文字不能完成查看，新增阵型连线会增加遮挡；因此把来源文字改成按钮，显示月音狐阶数、1起坐标、准确编号与「查看来源」。名单完全复用 battleStats 的存活、阶数、中心距离判定，不新增规则或覆盖算法。

点击来源调用 BattleInspection.showAlly：按准确编号校验仍存活，清除种类/存活筛选，保留排序，选中月音狐并将焦点移至灵兽实例下拉框。目标详情沿用编号 key，当前属性重新收起。来源按钮支持 Tab/Enter/Space，触控高度至少44px，320px视口文本换行无横溢。无来源、倒下者、狐或桃不出现来源按钮。

不增加返回栈、覆盖伙伴列表或新的状态；查看目标后可沿用下拉框、逐只翻看和阵型选择。图鉴往返保留目标，关闭详情继续保留暂停。

保持引擎/规则/数值/RNG、3格接敌、content prototype-2026-10-22-v24/schema2、保存/收藏/备份格式容量、素材、依赖及默认命令。

验证：真实Combat来源投影（同阶多狐、编号0、倒下/低阶/范围外排除）与SSR可访问文案；浏览器自然第50关暂停，筛选与排序后准确定位、键盘、图鉴往返、390/320视口及正式档只读核对。既有光环判定测试继续通过。

自审：范围仅限来源导航，来源模型无复制状态，命中值与来源口径保持一致。按用户持续「提交并下一步开发」授权直接实施，设计不单独提交，新开发留待下次提交。
