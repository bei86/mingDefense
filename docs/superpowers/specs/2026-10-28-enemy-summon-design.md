# 敌人当前召唤状态

上一轮已提交3bf73f7。用户持续授权“提交并下一步”，本轮自行实现、自审和验收，不派代理，新开发留工作区。

## 设计

敌人详情增加默认收起的“当前召唤状态”，仅存活鸣咒犬和首领显示。读取实例nextSummon、phase2、frozenUntil及当前关卡配置，列当前阶段单次召唤参数、后续间隔、该来源直属存活咒影/上限。普通敌人、分裂和子代不显示。

相比在战斗HUD增加持续倒计时，放入暂停详情不占战场；相比仅展示敌情静态规则，实例状态能区分当前计时、阶段与容量。已有衍生来源名单继续负责逐只查看，不重复增加名单或导航。

仅在召唤已启用时显示max(0,nextSummon-time)。正常0显示“待判定”；冻结分别显示冻结剩余和“解冻后召唤计时”，0显示“待解冻”。不合并两个时钟，不以计时到点承诺出怪。未启用的首领明确“进入第二阶段后启用”，不按低生命提前推测阶段；旧数据阶段缺失说明未记录，计时缺失不补造0。开场启用首领即使阶段缺失仍可读真实计时，但单次参数说明沿用未强化阶段。

容量只计hp>0、kind为summoned_wolf且owner严格等于来源id的直属咒影，编号0有效，其他来源/孙代/分裂不混入。列配置单次数量而非预计实际数量，并说明到点按空位结算；满额本次可能不生成，之后仍按周期再判定。首领阶段改变后单次数量从phase2取值，保留已有nextSummon，不提前重算计时。

沿用现有折叠样式，按敌人id重置；敌情档案挂起返回保留，暂停期间计时不流逝。纯投影无引擎调用或持久化。
