# 阵型应用前后首目标对照

目标：应用阵型前能比较当前与预设的首个寻敌目标，辅助前排和仇恨布阵。

选择在预设面板加入默认收起的三入口对照。相比常驻完整受击顺序列表，减少手机面板负担；相比模拟整场战斗，不引入胜负或伤害预测，也不会试应用预设。

- 只在planFormation成功时提供入口。展开后对每个config.waves.spawnColumns参考列，分别调用现有targetingPreview(current,column)和targetingPreview({...current,units:plan.units},column)，取first。实际队伍映射全部沿plan，不重新按种类匹配。
- 展示第几列入口、当前与应用后各自的灵兽名称、阶数、实例ID、仇恨和左上起点坐标；无目标显示“无上阵灵兽”。相同实例仍保留位置对照，不声称伤害变化。
- 文案明确固定敌人在入口参考点，先前排、同排低阶、高仇恨、距离和ID消歧；备战不计。首目标不等于抵达或首次命中时刻、阵亡顺序，实战移动、多敌人和首领技能可改变承伤。
- 默认收起、44px summary、键盘可展开；只展开时计算，切槽重置收起。每个入口独立卡片，当前/应用后竖排，320宽不溢出，沿父弹窗滚动。
- 纯投影不创建Combat、不tick、不消耗RNG或撤销，不改当前Preparation/plan。原阵容差异、站位变化、应用/撤销和独立预设存储保持；不改数值、规则、3格接敌、存档格式、依赖或启动命令。新功能留工作区，不提交、不推送。

验收：与实际enemyTarget/stepCombat的当前/应用后首次寻敌一致，覆盖多格前排、阶数/仇恨、同类距离随入口变化与ID稳定匹配、备战排除/当前空场、错误方案隐藏、重复只读/应用和撤销。浏览器正常保存→移动→对照→应用→受击预览→撤销，390/320展开、滚动、键盘、切槽及生产恢复。
