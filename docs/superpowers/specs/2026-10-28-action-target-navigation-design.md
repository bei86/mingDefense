# 暂停准备动作目标定位

目标：在「战斗当前属性 → 当前行动状态」中，直接查看准备攻击的敌人或准备施盾的己方目标，核对实际动作对象。

采用行内目标按钮，保留动作次数、目标名称/编号和释放剩余时间。单独的编号查询框增加操作，阵型连线不能表达敌方实例，所以沿用现有准确编号跳转。存活目标可点击「查看目标」；倒下或退场目标保持文字和无效动作说明，不提供跳转。无准备动作、桃和已倒下的施动者不出现目标按钮。

模型为每个准备动作派生 target:{side:'ally'|'enemy',id:number}，不保存进Combat。阵营由施动者种类决定，月音狐为ally，其余攻击灵兽为enemy；targetAlive沿用真实对象存活校验，双方同号不混淆，编号0有效。BattleInspection统一按side路由既有showAlly/showEnemy，保留准确定位、筛选清除与焦点行为；切页按现有生命周期，目标详情重新收起。查看不推进战斗，不新增返回栈。

保持引擎/规则/数值/RNG、3格接敌、content prototype-2026-10-22-v24/schema2、保存/收藏/备份格式容量、素材、依赖及默认命令。复用现有行内定位按钮样式，触控至少44px，320px文本换行无横溢，支持Tab/Enter/Space。

验证：真实Combat准备动作与同号跨阵营/编号0/同名敌人、无效目标、只读；SSR按钮文案与隐藏边界。浏览器自然第50关暂停捕获攻击和施盾准备动作，准确跳转、焦点与图鉴/敌情往返、390/320截图及正式档只读核对。

自审：定位的是已经准备的动作目标，不预测下一次寻敌或命中，不改变原动作排序和倒计时。用户持续授权本会话自主实施、自审和验收，不派代理、不单独提交设计，新开发留工作区。
