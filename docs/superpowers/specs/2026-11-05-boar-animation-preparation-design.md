# 岩甲豚攻击样板准备

用户已实测通过烬灵鼠实战，授权“提交并下一步”。下一步沿逐角色样板路线推进岩甲豚，先完成一组攻击，再沿经确认的攻击首帧补其他动作。

## 选择与范围

可一次铺开七个角色、先做岩甲豚四动作，或先确认岩甲豚攻击。选择最后一项：岩甲豚横占两格，先验证宽体角色的朝向、脚底和头部重击。一次生成六帧，禁止用静态图变换冒充肢体动画。当前没有岩甲豚新帧图，不接入不存在的纹理。

## 本次交付

1. 从public/assets/art/boar_idle.webp无损导出RGBA PNG参考，保留运行时造型与像素；另提供有透明安全边距的参考画布。原始立绘和发布图不改。
2. 在docs/art提供可直接复制的一整段提示词：3列×2行六帧，保持四足、苔绿岩甲、獠牙、当前朝向和共同落点。蓄力—短促顶击—收势，不跨格、不移动整个角色、不画地面及命中特效。明确只需生成这一张、上传哪个文件、保存哪里。
3. 新增离线帧图整理CLI，供图返回时检查。规则网格使用同一固定缩放和画布平移，不逐帧裁紧；保留透明度，验证帧数、边界、空帧、真实透明与缩放后的安全边距。输出WebP条、逐帧PNG、接触表和元数据到忽略的artifacts目录，不自动写入public或运行时清单。
4. 工具支持显式网格、输出画布尺寸及共同scale/offset；如果生成图不是规则网格或脚底漂移，先返回检查原图，不能自动拉伸单帧或“修复”为通过。最终游戏参考体宽高与原点必须在实际图审核后另行标定。

## 验证与后续

用标注为合成的测试帧验证相对坐标、共同缩放、不裁切、失败无写入和原图不可覆盖；此测试不代表新角色素材已生成。参考PNG与发布WebP解码像素一致，alpha真实、主体完整。人工查看参考画布，核对提示词与现有造型一致。

本次不调用付费生图，不修改战斗规则、现有角色动画、存档或生产首包。待用户生成六帧图后，再审核实际分格与脚底，选择共同缩放和落点，预览通过后接真实攻击事件；之后才能标为岩甲豚逐帧攻击完成。
