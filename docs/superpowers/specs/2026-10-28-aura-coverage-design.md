# 暂停月音狐攻击光环覆盖名单

目标：查看月音狐当前实际为哪些存活攻击灵兽提供光环，并能按准确编号定位伙伴，完成来源与受益者的双向查看。

选择折叠名单方案：直接铺开会拉长详情，阵型连线会遮挡，因此在月音狐「战斗当前属性」内提供默认收起的「攻击光环覆盖 · N只」。名单按站位从前到后、同位按编号排列，显示名字、阶数、1起坐标、编号，点击沿用 showAlly，清种类/状态筛选并保留排序、聚焦查看灵兽。目标属性重新收起，图鉴往返保留目标；不新增导航历史。

覆盖条件与既有来源列表共用UI只读判定：存活且达到解锁阶数的狐，目标为存活攻击灵兽，整体中心距离不超过固定光环半径。狐和桃不在攻击受益者名单，施盾范围与射程天赋不扩大光环。多狐覆盖分别列出受益者，不宣称叠加。无伙伴、未解锁、已倒下分别给出明确状态；非狐不显示覆盖面板。

验证：真实Combat与真实命中值核对覆盖、整体中心边界、低阶/倒下、桃狐排除、同阶不同编号、0编号、固定半径、重叠不叠加及只读；SSR检查状态与可访问名称。浏览器自然第50关暂停验证筛选/排序后跳转、来源往返、图鉴、键盘及390/320窄屏。
