# 岩甲豚六帧攻击接入

用户提供的1536×1024透明PNG是3列2行、每格512×512的完整六帧。保留原始文件和SHA256，按从左到右、从上到下读取。只接攻击，暂不制作待机、受击或倒下新图。

统一缩放0.625，输出384×288画布。横向偏移固定32px；以alpha≥96的最低脚底为参考，只修正纵向偏移，目标脚底y=256。保留头部前冲与身体压低，不按每帧边框重新缩放或横向居中。第一姿态的可见体积作为全片固定绘制尺寸，脚底和旧立绘的底线一致。原图方向固定，不因敌方位置翻转。

公共六帧攻击投影读取Combat.attacks和真实ally Flash，按种类隔离实例。前摇映射0/1/2帧，真实释放才进入3/4/5帧，收势210ms。动画只读取模拟，不改伤害、冷却、前摇、随机数或存档。暂停、选天赋、后台、倍速均跟随原战斗时钟；取消攻击不能假放招，死亡和结算复位。

有动画纹理时平时显示第一帧，避免新旧立绘每次攻击切换。受击仍使用现有色调，死亡仍使用现有淡出。减少动态效果时固定第一帧。缺动画纹理时回退旧静态立绘，加载与重试沿用现有流程。攻击帧不叠加旧整体前倾。

先审查大图、实际两格94×36绘制尺寸和6→1衔接，再发布WebP；记录外观差异与尚未完成的浏览器验收。公开素材保持lossless WebP，处理过程可离线重建。
