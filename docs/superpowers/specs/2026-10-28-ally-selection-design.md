# 暂停灵兽种类与状态筛选

上一轮已提交 `d75ee80`，本轮按用户“提交并下一步”持续授权完成设计、实现及验收，新开发留工作区，不另行审批或派代理。

选择在原下拉入口前增加种类与状态筛选，复用44px原生select。相比增加搜索文字框，八种灵兽可直接计数选择；相比重新排列阵线总览，筛选只改变详情候选名单，完整阵型仍保持。

种类包含全部及本场已上阵的实际种类，数量含倒下者、排除备战席。状态包含全部、存活、已倒下，计数基于当前种类；种类和状态取交集。同种多只按原行列/ID顺序保留。改变筛选保留仍匹配的实例，否则选首只；没有匹配则显示明确空态及可用筛选，不回退显示其他实例。缺失种类回全部，null/空战斗安全。

阵线总览始终显示全体；点击任一存活/倒下灵兽清除筛选，准确定位并聚焦查看灵兽。敌人锁定、准备普攻与预警行名单沿用原跨页入口，只允许有效存活目标，并清除筛选。普通切页再返回恢复全部、保留原实例；技能图鉴往返保留筛选、实例与展开状态，战斗保持暂停。

筛选只在详情组件内保存，不写Session/RNG/存档。战场顶部存活总数、锁定名单、当前属性、累计战报、技能图鉴、备战席说明与敌人页不改语义。保持规则/数值、3格接敌、content prototype-2026-10-22-v24/schema2、保存/收藏/备份格式容量、素材、依赖、默认命令。

验证纯模型的同种不同阶/位置、倒下者、空交集、备战排除、失效编号、旧战报与只读；SSR覆盖计数、筛选、空态和原入口。浏览器以隔离合法第50关自然战斗，验证筛选/图鉴往返、阵线总览与敌人反向定位、键盘和390/320窄屏，正式档只读不推进。
