# 同种高阶备战提示

用户“提交并下一步”已批准上一轮建议的战前提示。先提交已完成阵型分享与诊断（4fa078f），本轮新功能开发后留工作区，不自动二次提交或推送。

在现有战前检查中加入只读提示，比新增弹窗/自动换位更贴合当前手动布阵流程；既保留决定权，也可核对完整占格。无数值、寻敌、战斗、招募、存档格式、启动命令或依赖改变。

- 新纯模型reserveUpgrades(preparation)只检查已领取且在备战席的灵兽，与同种严格低阶的上阵灵兽配对；排除同阶/高阶/不同种/备战/未领取目标。候选复用真实swapError检查，备战满仍可直接合法换位。来源按阶数降序、ID升序，目标按阶数与ID升序。
- 结果包含独立的ID、种类、阶数、上阵左上坐标和完整占格副本，不泄漏可修改的原位置引用。无目标的备战不提示；无提示时原战前检查保持原内容。
- 战前检查收起时显示“同种高阶N只”，N按有候选的备战只数而非配对数。展开后列出高阶备战，目标列表默认收起，显示每个目标的阶数、编号与完整占格（1起点列/行）。两只备战可共享同一目标，只表示当前独立可换，不承诺能全部同时交换。
- 备战与目标都可点击选中，已选中再次点击保持选中；未准备好战场时禁用选择。提示不直接移动、合成、撤销、改变暂停或写存档；选择后按现有换位流程操作，原撤销继续有效。文案说明一次只换一对，无胜率或最优承诺。
- 每次整备重绘从当前preparation派生，移动/合成/遣散/换位/撤销后即时重算，不缓存原对象或保存重复状态；战斗时随整备面板隐藏。
- 独立ReserveUpgrades组件使用现有图片和配色；窄屏可换行，按钮至少44px，长目标列表沿页面滚动，不挡棋盘。正常战前检查的完整空位/合成统计继续只在展开时计算。

验收：纯模型覆盖八灵完整占格、真实换位成功及撤销、满备战、无候选、只读资源/RNG/撤销、引用隔离与重算；浏览器以正常UI创建备战高阶与场上低阶，验证选中不移动、实际换位提示消失、撤销恢复、390/320宽及正式生产入口。无新调试入口或正式存档注入。
