# 战斗模拟独立调度修正

下一步先完成已有实战运行问题的修复。前序多轮浏览器验收记录战斗推进缓慢；修正前App与Phaser各有requestAnimationFrame，模拟随App的视觉回调运行。临时帧探针在长时间操作间没有收到连续回调，尚不能据此声称是CPU瓶颈或怪物数值问题。

本轮选择独立25ms计时器驱动GameClock，保持50ms固定模拟步长与100ms HUD刷新。Phaser仍使用自己的视觉循环。该方案能让模拟不依赖视觉帧回调；提高250ms卡顿阈值可能引入突然快进，直接调关卡数值则无法验证实战时钟，均不在本轮采用。

GameClock超过250ms的墙钟间隔仍丢弃，不追补长停顿；暂停、后台、失焦、天赋选择仍停止推进并清除长按。UI卸载/开发热更新清理计时器，不能生成双倍战斗循环。计时器延迟时仍按实际performance.now推进，不以回调次数计算战斗时间。

生产改动仅为调度器与App接线，不改变3格距离、画布清晰度、速度倍率、出怪配置、技能、经济、存档结构或内容版本。不新增正式玩家调试面板。现有用户已要求继续下一步，作为既有运行问题修正直接实施，不自动提交或推送。

验收包含：没有requestAnimationFrame时1×/2×墙钟比率；与直接50ms仿真的确定性结果相同；暂停/天赋停表与清除长按；长停顿丢弃、重新继续；清理后无推进及重复循环；实际浏览器计时与出怪进度、暂停继续、窄屏。自动测试与浏览器证明分别记录，不把固定阵容当成正常经济通关。
