# 敌人有效状态筛选设计

用户持续授权“提交并下一步”，提交锁定压力筛选后实施本轮。目标：在暂停敌人详情快速浏览冻结、霜尾缓行、易伤及无上述局部状态的存活实例。

在敌人种类/排序控件之间增加状态下拉框，选项为all/frozen/slowed/vulnerable/unaffected。相比用详情文案解析状态，选择投影增加类型化statuses数组，和现有效果文案在同一有效期判断中生成，避免重复计算过期；相比战场额外标记，无需改变画布。只读当前Combat，状态截止时间严格大于battle.time才算有效，到期边界立即排除。沿用现有易伤倍率未记录/0的有效期语义，不自行修正规则。

数量基于当前种类；状态可重叠，三状态数量不可相加当敌人数。“无局部状态”只指三者均无，全场迟滞天赋另列，不计入局部缓行。死亡者和未出场者不计，不推断下次状态或剩余伤害。

更换种类或状态保留匹配实例，失配选当前排序首只，空交集保留控件和明确提示，无实例/详情/档案/导航；全场无活敌仍用原空态。排序保留当前实例；档案往返保持种类、状态、排序和编号。普通切页重置。衍生来源/子代快捷定位清种类和状态并保留排序，精确聚焦实例。外部锁定/预警入口沿用现有新挂载默认全部。

不改引擎/规则/数值/RNG、3格接敌、content prototype-2026-10-22-v24/schema2、存档/收藏/备份、素材、依赖与默认命令。

验证真实Combat的重叠/到期/缺字段/全场迟滞/死亡/同种多实例/编号0、计数和只读；验证筛选/排序/选择/导航与空态，浏览器独立试玩的自然非零状态、档案返回、跨筛选快捷入口、切页、键盘、320/390视口。全量测试/构建/启动边界/格式检查通过，明确非真机与非生产包浏览器验收。
