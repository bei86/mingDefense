# 阵型应用前站位预览

目标：阵容兼容时，应用前看清哪些灵兽会换位、上阵或退回备战席。

选择在原预设面板增加简短统计和默认收起的逐只明细。相比额外确认弹窗，不增加应用步骤；相比在小图叠箭头，坐标清单在手机上更清晰且能区分同种同阶实例。

- 直接比较当前拥有实例与已有planFormation成功结果，按实例ID关联，保留当前阵容顺序。不得自行重匹配、模拟应用、重生成预设或修改状态。
- 只列位置变化的实例，分为场内换位、备战上阵、退回备战；总数为三者之和，未动者不列。无预设、校验失败、当前已是此站位时不显示此区；原阵容缺少/多出提示保持。
- 展示名称、阶数、实例编号及起点→终点。坐标一律从1起算，标明多格坐标指左上起点，完整占格仍看上方小图。null位置显示备战席；不展示合成、伤害或收益推断。
- 统计常显，逐只明细用原生details/summary收起，可鼠标和键盘展开；切槽以slot作为组件key重置展开。320宽可换行，父弹窗负责纵向滚动，不新增内部滚动区。
- 直接派生，无effect/memo/存储。沿用原应用、关闭与撤销；不改匹配规则、存档格式、数值、3格接敌、依赖、素材和启动命令。新功能不提交、不推送。

验收：真实plan覆盖场内换位、上阵/退备战、重复同种同阶按ID稳定映射、未动实例过滤、满36格循环换位、无效/锁格/阵容差异/相同站位隐藏；预览与实际应用逐只一致、撤销还原、全状态只读。浏览器正常保存→移动→查看→应用→撤销，以及390/320布局、键盘展开与切槽；生产页验证原存档和预设恢复，不注入状态。
