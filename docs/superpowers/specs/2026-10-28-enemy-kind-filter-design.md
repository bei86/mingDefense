# 暂停敌人详情按种类筛选

## 目标与方案

召唤和分裂让“查看敌人”下拉框中出现许多同名实例。增加一个“敌人种类”下拉框，列全部及当前实际存活的种类与数量，便于选择首领、召唤者或衍生怪，再核对具体编号和生命。

沿用暂停详情的深绿、金色、薄荷配色及44px原生select，不增加常驻HUD。相比多组展开列表，单个筛选入口占用较少空间；相比种类按钮网格，手机上不堆满操作区。用户持续授权提交后继续开发，本轮直接设计、实施和验证。

## 交互规则

- 默认全部，显示总只数；各项显示实际敌名及只数，首领名来自当前关卡投影。只列存活种类，召唤狼与普通狼、分裂碎片与母体分别计数。
- 复用enemyInspection已经排除死亡的实例列表。保持其首领优先、其余按编号顺序，不改原数组或战斗对象。
- 选择种类时，当前实例属于该种则保留，否则选择筛选后首个实例，并同步父层enemyId。查看敌人列表仅列筛选结果。
- 当前类别不再存在则退回全部；选中编号无效时回退到当前结果首个实例。无敌人时保持原空态，不显示无效筛选。
- 灵兽锁定列表跳到敌人、预警快捷进入仍默认全部并定位指定实例；切到灵兽/后续敌袭再返回敌人会重新默认全部，父层选中实例保留。由敌人跳到灵兽后仍可沿原技能图鉴流程往返。
- 显示“当前显示 N / 总数 只”，解释只包含当前存活敌人，未出场队列在“后续敌袭”；筛选不表示攻击优先级。

## 约束与验收

保留战斗规则/数值/RNG、3格接敌、content prototype-2026-10-22-v24/schema2、存档/收藏/备份格式与容量、素材、依赖和默认命令。筛选仅为面板本地状态，不写存档，不推进时间或改变锁定。

纯投影测试覆盖每类计数、衍生分开、零/负生命排除、类别与编号失效、保留或切换选中及全量JSON只读；SSR验证默认全部和实际选中实例、预警入口不被筛掉、空态。Chrome独立第50关通过正常UI操作筛选、具体实例切换、返回全部及跨页跳转，390/320尺寸截图与溢出检查，保留正式档。
