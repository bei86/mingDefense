# 青锋隼攻击动作素材准备

岩甲豚四动作已提交为4b37fc8。用户授权“提交并下一步”，继续单角色推进，第三只选择原始三灵中的青锋隼。其2×2格、悬空宽翼形体与鼠/豚不同，先完成攻击样板，再从实际接入的首帧补其他动作。

可一次生成四动作、先强化程序摆动或先做攻击六帧。沿用已确定的最后一条路线：先确认真实翼部动作、共同体积和悬空基准，不把静态立绘旋转/缩放当作新动画。

以public/assets/art/sword_eagle_idle.webp为唯一参考：384×317 RGBA，完整保留青玉/深青羽毛、白胸腹、金眼、玉剑形冠羽、黄脚及深色爪、右前方三分之四朝向和半展开双翼。无损导出reference.png，再不缩放地放到512×512透明画布(64,97)，得到reference-canvas.png。独立命名空间docs/img/animations/sword_eagle，不覆盖原PNG和发布图。

攻击图要求3列×2行共6帧，每格512×512，整图1536×1024。姿态为参考悬停、收翼蓄力、稍加收紧、短促向前下方振翼、收势、回参考悬停。角色保持原布阵中心，胸腹/躯干是共同空间基准；不以翼尖包围框逐帧居中，不套用地面四足的脚底锚点。双翼/冠羽/尾羽/爪部完整、不跨格；悬空不增加地面阴影。剑阵与命中效果由游戏另画，帧内不生飞剑、弹道或大范围光效。

提示词整段独立可复制，提供上传文件与原图保存位置。本轮只导出参考、生成可复制文档和记录来源，不调用生图API、不安装依赖、不接入不存在的纹理、不改伤害/技能/随机流/存档。收到整张新图后再审实际边界/透明/动作连续性，制定共享缩放、胸腹落点与真实释放时机；参考导出不等于逐帧攻击已完成。

验证导出PNG与发布WebP解码RGBA逐字节一致，画布粘贴区域一致且外围透明，源图哈希不变；查看参考确认姿态/朝向/边距。核对提示词帧数/布局/文件名，运行发布素材完整性检查与diff检查。无需本轮浏览器验收，已有鼠/豚实机验收边界继续保留。
