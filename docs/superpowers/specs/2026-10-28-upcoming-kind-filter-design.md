# 后续敌袭种类筛选设计

持续授权“提交并下一步”：已提交敌人有效状态筛选，本轮完成后续固定队列的种类筛选。

在现有后续敌袭页增加“后续敌袭种类”下拉框。选择单一种类时仅列该类的实际固定队列，仍按原队列顺序、每页8只；改种类回第一页。相较将上方种类档案按钮改为筛选，不改变原入口含义；相较新增独立页，复用当前时间、入口、分页与档案返回生命周期。

顶部“未出场固定敌人”及各类数量始终统计完整未消费队列。筛选时明确显示匹配数/全部未出场数，范围编号及页码为筛选内序号，隐藏数量仅统计符合筛选但未在本页显示的条目；逐条index仍是原始出怪队列绝对索引，绝不重新编号。使用spawnIndex而非时间/击杀数判断消费，保留同刻顺序和已到时待出场语义，不改计划时间和入口列。

upcomingEnemies第三参kind默认all，投影新增kind/matched。仅提供实际剩余种类；无该种类时归回all。队列为空隐藏筛选，保持原“固定出怪已结束”及结束态“已全部执行”说明，不能冒充战斗胜利。已结束但仍有未执行计划时仍可按类浏览，明确不会继续出场。旧kind缺省按wolf，召唤/分裂场上实例不混入。

档案往返保留筛选和页码，各种类档案入口仍使用完整未出场统计；普通切换战场信息页再返回默认全部第一页。使用原select和分页样式，键盘及320/390视口可操作。

不改引擎/规则/数值/RNG、3格接敌、content prototype-2026-10-22-v24/schema2、存档/收藏/备份、素材、依赖或默认命令。验证50关真实队列按类拼接无重漏、稀疏索引和同刻顺序、分页归一、旧数据、结束态、只读；浏览器独立合法开局验证筛选/翻页/档案/切页/键盘/窄屏，不推进正式存档。
