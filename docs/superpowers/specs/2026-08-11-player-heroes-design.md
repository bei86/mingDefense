# 我方英雄与升阶设计

日期：2026-08-11

## 1. 文档范围

本文档维护我方英雄的占格、定位、六阶属性、技能质变和实机校准状态。总体玩法、关卡、架构和在线能力见 [小妖卫道玩法复刻项目设计](./2026-08-10-demon-defense-game-design.md)。

完整版本以原作八种小妖的占格、战斗定位、六阶攻击成长和三阶、五阶技能质变作为玩法参考。原作名称只用于设计对照，发布版本必须替换为原创名称、角色形象和技能表现。

## 3. 数值解释

- 表中数值是公开攻略给出的面板或等效单次攻击值，不直接代表每秒伤害。
- 天蓬猪的数值已经计入普通攻击 120% 倍率。
- 熊大师会发射三道拳罡，表中数值按单段面板记录；多弹命中规则需在战斗公式中单独计算。
- 御剑鹰五阶的 480 在公开页面中发生文本损坏，是根据上下阶数值和技能公式还原的待实机校准值。
- 生命值不从公开攻略推测，由用户后续提供。
- 英雄配置在设计阶段允许生命字段为空，但 M1 战斗实现和生产配置校验必须拒绝缺失生命值的单位。

## 5. 技能节点

### 5.1 招财桃

- 每秒产生金络果。
- 公开攻略给出的六阶产出疑似为 0.050 / 0.056 / 0.063 / 0.071 / 0.166 / 0.200。
- 二阶在来源页面被写成 0.556，整组数据在实机确认前不进入正式数值配置。

### 5.2 北冥鱼

- 基础攻击附带减速。
- 三阶后获得冰冻。
- 减速比例、持续时间和冰冻时间由实机校准。

### 5.3 御剑鹰

- 基础攻击造成范围伤害。
- 三阶后留下持续 2 秒的剑阵，造成两次 48% 攻击伤害。
- 五阶后攻击次数翻倍。

### 5.4 齐天猴

- 基础攻击造成直线贯穿伤害。
- 三阶后使命中目标受到的伤害提高 10%。
- 五阶后每次攻击造成两段伤害。

### 5.5 天蓬猪

- 普通攻击倍率为 120%。
- 三阶后每三次攻击触发一次 1.5 倍普通攻击，并造成 100% 攻击力的范围伤害。
- 五阶后改为每两次攻击触发。

### 5.6 熊大师

- 一次释放三道拳罡。
- 三阶后拳罡命中会继续分裂。

### 5.7 火云鼠

- 没有基础被动，定位为低占格单体输出。
- 专属 Buff 可对生命低于 30% 的敌人提高 50% 伤害。
- 另一个专属 Buff 提供 10% 斩杀概率，Boss 免疫斩杀。

### 5.8 仙乐狐

- 每次行动为目标提供其最大生命 3% 的护盾。
- 三阶后使附近友军攻击提高 10%。
- 五阶后开战提供额外充能，充能值由实机校准。

## 6. M1 实现范围

M1 只实现三个玩法代表：

- 火云鼠：单格、单体输出。
- 天蓬猪：双格、单体暴击和范围触发。
- 御剑鹰：四格、范围输出和残留剑阵。

三者用于验证单位占格差异、同名合成、六阶属性读取、三阶及五阶技能切换和自动战斗。正式进入 M1 战斗实现前，必须先补齐这三个英雄的六阶生命值。
