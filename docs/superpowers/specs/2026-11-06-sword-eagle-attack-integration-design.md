# 青锋隼六帧攻击接入

用户提供1536×1024 RGBA原图并要求下一步，按已确认的单角色攻击样板路线继续接入，不重复索取批准。新图SHA256为97d94e51145d9a62ad0f738a0e4dba9e4d7d448e92dbe2b26ef269413bb29cb2。六个角色的主轮廓透明，底图含alpha1–8的微弱背景残影，第4帧右翼延伸到x565，跨越标准512边界，但与第5帧x568起的轮廓分离。

直接均分会裁翼；重新生成会增加用户成本。本轮采用按实际间隙切图，底行第一处分隔为x567，整组缩放0.625，清理alpha<=8的背景残影，保留原始下载图不变。每帧放入相同448×352画布，人工审核胸腹中心对齐(240,224)，保留振翼轮廓变化；不按翼尖包围框逐帧居中或按地面脚底对齐。共同绘制原点(240,180)，固定348×258运动包络决定显示缩放，避免胸腹直接放在棋盘中心导致冠羽遮住上方血条；最宽双翼仍完整留在2×2区域。输出无损WebP、处理报告、放大/2×2棋盘尺寸接触表和独立预览，先查看再发布。六帧头冠/翅膀/尾羽/爪须完整，包含跨格的翼尖。

沿AttackFrames增加sword_eagle种类，CombatFeedback独立实例投影真实前摇和Flash，Battlefield仅对鹰读取该帧。前三帧准备，第4帧真实释放，之后70ms/帧收势。动画未激活、死亡、结算或减少动态均取首帧；受击仍沿旧tint、倒下沿旧alpha，不伪造尚未收到的其他动作。纹理缺失回原静态立绘。公共清单加载/计数由现有数组更新，2×2布阵、伤害、冷却、剑阵、随机状态与存档不变。

验证必须覆盖真实鹰攻击/剑阵关联、取消前摇、同种实例与其他物种隔离、暂停/倍速/后台/减少动态/换关和读Session无副作用。素材检查核对原图与发布哈希、固定尺寸、共同缩放、锚点、不裁翼。运行类型/构建及完整默认测试，尝试浏览器八灵试玩检查实际2×2显示；若工具不可用明确记录，不把离线接触表当作浏览器验收。
