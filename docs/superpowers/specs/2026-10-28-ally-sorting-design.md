# 暂停灵兽排序

上一轮已提交f8b7103。按用户“提交并下一步”持续授权，在本会话顺序设计、实现、自审与验收，不派代理或另行审批，新开发留工作区。

在灵兽筛选后增加44px「灵兽排序」select：站位（默认）、生命比例从低到高、锁定数量从高到低、本关伤害/承伤/提供护盾/护盾吸收/产钱从高到低。相比自动切换到首名，保持当前实例便于比较；相比额外排行榜，复用现有候选名单与累计贡献详情，不增战斗HUD。

- 排序只作用于当前种类/状态交集后的实例名单；种类数量、状态数量、顶部总数及完整阵型保持。站位按行列ID，其他同值也按站位/ID打破平局，不依赖输入顺序。
- 生命按hp/maxHp实际比例比较，倒下者为0、排在存活残血前；缺失/非有限值排在真实0后。贡献用已有本关记录，旧数据缺失标「未记录」并排最后，不当成0；数值展示向下取整、排序用原值。锁定为缓存数量，不是伤害预测。
- 非站位排序的候选文案追加所选指标值，生命显示百分比（最多一位小数）；站位文案保持。界面说明生命比例包含倒下者，贡献仅为本关累计，非DPS。
- 改排序保留匹配的当前实例；筛选后当前不匹配时按当前排序选首只。空交集保留排序入口，无无效详情。技能图鉴返回保留筛选/排序/编号；普通切页恢复默认排序，保留选择。阵型/敌人快捷定位清筛选、保留当前排序并准确定位/聚焦，不按排序首名覆盖目标。
- 不写Session、存档或RNG，不改变部署、仇恨、战斗或收藏。保持规则/数值、3格接敌、content prototype-2026-10-22-v24/schema2、保存/收藏/备份格式容量、素材、依赖、默认命令。

测试核对真实投影中比例与绝对血量差异、倒下者、同值站位/ID、旧记录/部分缺字段、浮点原值、空筛选/缺编号、全JSON只读；浏览器用独立第50关自然战斗验证排序、当前实例保持、图鉴往返、快捷定位、筛选与普通切页、390/320布局，正式档只读。
