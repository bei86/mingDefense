# 烬灵鼠动作预览方案

烬灵鼠四组动作已有素材和运行时接入，但普通战斗不方便停在指定帧，重伤也不容易反复触发。延续单角色样板先验收再扩展的路线，下一步增加开发版独立动作预览。

可选路线为继续只用离线GIF、在正式战斗增加调试按钮、独立开发页。选择独立开发页：复用Phaser和ArtLayer的真实纹理、原点与缩放，不在正常战场增加操作，也不需要运行Session或访问存档。

入口为开发版启动前分流的`?preview=mouse-motion`，开发试玩菜单提供入口。生产构建排除此页面、代码和入口。未知preview值沿原启动流程；正确preview值优先于其他试玩查询，不先创建游戏实例。离开提示沿用现有开发试玩规范。

页面延续深绿与米金配色，以画面为主、文字控件位于画布之外。画布同屏给出52像素单格尺寸和4倍放大对照，绘制网格与共同脚底基准，使用168×216参考尺寸及各动作实际原点。放大窗用于查边缘，不代表战场中角色会变大。

提供待机、攻击、受击、重伤选择，播放/暂停、重播、上一帧/下一帧、帧滑条、1倍/2倍速、减少动态与背景色切换。待机循环，其余一次后停末帧。攻击逐帧预览每帧70ms，仅用于检查素材连续性；真实准备与释放时机仍须八灵实战验收，不在此页伪造伤害、敌人或投射物。

切换动作从首帧开始；减少动态暂停并固定所选动作首帧，重伤固定末帧，逐帧操作禁用，系统减少动态优先。失焦/切后台冻结，恢复不补跑。尺寸变化只影响显示，不改时钟。页面无音效、无存储，返回正式地址才按正常流程加载原检查点；另提供进入八灵实战的链接。

缺素材明确显示缺失，不能用其他动作伪装通过；允许重新加载。组件卸载或StrictMode清理时销毁Phaser和监听器，不重复创建画布。控件有标签、焦点态，窄屏垂直排列，无横向溢出。

验收包括一次动作末帧保持、暂停逐帧、切换/重播、速度、后台和减少动态、缺图说明、嵌套部署路径、存储访问隔离、生产包剔除。浏览器不可用时明确记录未完成的实际交互与画面验收，自动测试不能代替浏览器截图。
