# 战报收藏备份与导入

沿用用户“提交并下一步开发”授权，本步在战报收藏内增加默认收起的备份入口。上一轮已提交3be7f00，本步完成后留工作区，不推送。

选择独立收藏备份：不修改战役存档格式，不把收藏塞入战役恢复流程，不接云端。生成当前收藏的JSON备份，可复制、下载和手动全选；导入支持粘贴与本地文件，先校验并预览，再明确确认合并。

格式包含固定kind标识 `ming-defense-report-collection`、schemaVersion1及entries，保留关卡、结果、原收藏时间和战报全文。复用原收藏校验：最多10条、单文64KiB、库768KiB，输入备份最大1MiB。不同类型/未知版本/无效或重复条目/过长内容整体拒绝。战报按纯文本处理，不解释HTML。备份不含战役进度或阵型。

预览按全文去重，显示新增及重复数量、新记录的关卡/结果/原时间/完整可展开文本。确认时重新读取收藏并重算；若预览后收藏发生变化，拒绝写入并要求重新校验。导入新增条目重新分配本地唯一安全ID，保留原createdAt，已有记录及顺序不改；满10条时整批拒绝，不部分导入、不自动删除。全部重复成功但不写存储。写入一次完成，失败保留原数据且不显示成功。只操作独立收藏键。

收起、修改输入、选择新文件、取消和重新读取清除待确认预览；本地文件异步读取期间禁止校验/确认，过期读取不得覆盖新输入或卸载后的状态。不可用库不生成/导入，提供原重读入口。开发试玩继续使用临时收藏端口，不读取正式库。

保留原单篇导出和删除确认。备份区与删除确认不同时开放，避免动作含糊。导入后刷新父列表，并清空输入/预览；焦点回输入。320/390宽可换行、可滚动，按钮至少44px高，弹窗背景滚动锁保持。关闭暂停中的收藏后仍暂停。

验证模型往返、全文去重、时间/编号、上限、坏库、不同类型、UTF8字节、写失败、预览过期、一次写入及其他键不变；文件大小/读取失败；真实Session战报导出与隔离库往返。浏览器实操临时库导入预览/取消/确认/重复/错误、导出复制与下载、文件回读、窄屏和生产空操作。规则、数值、随机流、依赖、启动命令与战役存档不变。
