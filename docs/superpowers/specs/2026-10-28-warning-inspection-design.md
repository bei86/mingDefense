# 横扫预警快捷查看

用户持续授权“提交并下一步”。上一轮提交后，本轮原生顺序实施，新增开发留工作区，不另启代理。

## 方案

采用每道预警上的“暂停查看”入口：同排首段与追击可各自选择，点击后暂停、释放聚灵，打开现有战场详情的敌人页，选中来源首领，并默认展开对应预警的波及名单。关闭仍返回暂停菜单，玩家主动继续才恢复战斗。

仅保留原菜单虽不增加UI，但查看路径长；新做一套预警弹窗会重复敌人/灵兽详情。复用现有详情能沿用名单跳转、图鉴返回及焦点管理。

## 数据和交互

预警目标是BossWarning中的source、从1起的row和echo，不含会被冻结调整的due。事件处理额外带当前展示的Combat引用；重新核对同一场战斗、combat阶段、无待选天赋、存活首领及仍存在的对应预警。失效点击无操作，不能打开另场同编号来源或暂停天赋/结算。

详情入口状态使用单个对象，普通菜单进入时不带预警目标；关闭后清除目标。初始目标只用于初始化敌人页与对应名单，玩家可正常切换敌人、灵兽、后续敌袭，折叠名单或进入图鉴，返回不自动恢复战斗。

HUD沿用深绿与暖色/淡紫，每条入口至少44px高，有明确的“暂停查看”文字和包含行/首段或追击的无障碍名称。保持原列表最多两条和额外计数，窄屏允许换行，不添加浮层和动画。暂停详情顶端显示所点预警摘要，所选首领的预警区提前展示，减少寻找距离；仅对应名单默认展开。

## 边界

不改战斗规则、数值、RNG、3格、content v24/schema2、存档/收藏格式容量、素材、依赖和默认命令。不预测伤害，显示当前完整占格的存活名单，实际释放仍重新判断。

验证包括事件时的过期/来源失效/跨战斗拒绝、真实Session暂停和聚灵释放、只读状态、SSR初始敌人/预警展开、普通菜单默认行为；独立自然战斗下鼠标和键盘入口、名单与图鉴往返、暂停保持、320/390布局。正式档不用于试玩。
