# 第 1 关实施计划

用户已授权“继续下一步”，直接实施 M0 + M1。

## 交付

Vite + TypeScript + React 操作界面 + Phaser 3 战场。第 1 关、三个英雄、1–3 阶；招募、扩地、两位备战席、布阵、合成、自动战斗、聚灵石、暂停、倍速、结算和检查点重试。其他关卡、Buff、存档和 Boss 留至 M2/M3。

## 步骤

1. 建立工程及开发/构建/测试脚本；直接读取已确认的 JSON 数值配置。
2. `src/game/content.ts` 提供 M1 内容；`session.ts` 管理准备期命令、商店 RNG、原子放置/合成/扩地、单次撤销和开战检查点。
3. `combat.ts` 实现独立 50ms 模拟器：目标选择、移动、前摇、伤害、剑阵、波次、能量及胜负优先级；`clock.ts` 控制倍速和暂停。
4. `src/ui` 使用森林青绿、暖金和宣纸色竖屏界面；`src/render` 绘制原创几何角色。DOM 提供棋盘点击/拖动、商店、备战席等操作，React 定期刷新 HUD。
5. 验证非法命令无副作用、占地/合成/撤销、种子一致性、未来波次、完整 18 敌、技能公式、能量、倍速、检查点回滚及奖励幂等。
6. 类型检查/测试/构建后，启动服务器，浏览器验证 320/390px 和桌面操作、战斗及结算，保留截图。

## 约束

会话是唯一状态来源；模拟器不依赖 React/Phaser；状态可 JSON 序列化；暂停和失焦清除聚灵石按住状态及墙钟累积。非法放置不改变状态；同种同阶合成保留目标 ID/位置。战斗禁止改布局，中止/失败重试恢复完整检查点，胜利奖励只领一次。配置中的 P 值仍是临时设计。验证报告区分规则测试和浏览器实测。
